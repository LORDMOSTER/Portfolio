# ⚡ ENGINEERED SYSTEMS // PERSONAL PORTFOLIO & TELEMETRY DASHBOARD

A high-performance, dark-themed developer portfolio and real-time operations dashboard. This application is architected to showcase a chronological roadmap of engineering deployments—ranging from low-level systems programming to containerized full-stack applications and offline AI/ML pipelines. 

Developed exclusively with a strict, type-safe, hardware-accelerated frontend architecture.

---

## 🛠️ THE CORE ARCHITECTURE

The interface is built to function like an interactive tactical operations command center, divided into specialized operational subsystems:

* **Executive Profiler:** High-density summary of engineering credentials, institutional metrics, and core focus profiles.
* **Winding S-Curve Roadmap:** A custom, visually fluid, chronological vertical pipeline tracking engineering maturity across 10 separate production-grade builds.
* **Live Telemetry Engine:** An asynchronous telemetry hub communicating natively with external services (including LeetCode and the GitHub REST API) to monitor real-time competitive programming performance and continuous repository additions.
* **Hall of Records:** A secure digital matrix presenting authenticated academic credentials, NPTEL specialized badges (Gold, Silver, Elite), and competitive symposium accomplishments framed by an interactive, custom matrix-glitch component.

## 🚀 THE DEPLOYMENT ROADMAP (CHRONOLOGICAL ORDER)

1. **Gestodrive:** A real-time human-computer interface (HCI) translating spatial geometry and hand-tracking coordinates into direct keyboard emulations via OpenCV and MediaPipe to play driving simulations hands-free.
2. **Viso Vibe:** An integrated emotion-driven media orchestrator utilizing deep learning computer vision frameworks (DeepFace) to parse webcam frames and programmatically command Spotify playback states via secure API OAuth.
3. **SentimentAnalyser:** A natural language processing tool utilizing a dual-pipeline approach (Hugging Face DistilBERT alongside a custom trained Bidirectional LSTM network) to calculate emotional valence and contextual text probabilities.
4. **Coloré:** A sub-millisecond precision design utility evaluating image canvases at the pixel level, matching extracted RGB profiles against an extensive index through custom coded 3D Euclidean distance math.
5. **MiraX OS Shell:** A custom multi-user command-line interface (CLI) framework built using Windows Batch Scripting, pushing legacy constraints to handle file encryption ciphers, user access controls, and task automation arrays.
6. **Chat-Space:** A scalable real-time P2P communications platform engineering low-latency messaging threads and serverless video infrastructure through FastAPI, native WebRTC engines, and socket-based network handshakes.
7. **MindX RAG Platform:** A local, air-gapped document intelligence utility performing text chunking, persistent database vector storage (ChromaDB), and contextual inference using local llama3 LLMs over private corporate PDFs.
8. **Campus Canteen POS:** A bidirectional real-time dining hub wiring student apps to zero-refresh kitchen consoles through persistent WebSockets, embedded local databases (SQLite), and external QR fulfillment protocols.
9. **Krishi-Route Logistics:** An agricultural optimization engine evaluating regional commodity indexes and calculating geospatial route expenses through mathematical Haversine calculations to match farmers into collaborative cargo transport pools.
10. **AI-Receptionist Agent:** A native speech-to-speech voice automation agent streaming digital audio bytes through OpenAI's Realtime protocol and LiveKit telephony nodes to deliver natural turn-taking and conversational sub-second latency.

## 🛠️ LOCAL CONFIGURATION & DISPATCH

### Prerequisites
Ensure your local compute station features **Node.js (v18.x or later)** and **npm** installed.

```bash
# 1. Initialize local clone of the core matrix
git clone [https://github.com/LORDMOSTER/Portfolio.git](https://github.com/LORDMOSTER/Portfolio.git)

# 2. Enter the system root directory
cd Portfolio

# 3. Inject and mount application dependencies
npm install

# 4. Boot up the high-speed local Vite environment
npm run dev
